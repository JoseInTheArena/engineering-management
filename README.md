# Resources for engineering managers
A list of engineering manager resources I have read and found useful

## Articles

- [The Engineer/Manager Pendulum](https://charity.wtf/2017/05/11/the-engineer-manager-pendulum/) - Charity Majors on switching between IC and management roles
- [What's Expected of Engineering Managers](https://charity.wtf/2022/01/11/what-does-your-engineering-manager-do-all-day/) - Understanding the EM role
- [How to Lead a Project](https://www.jmoses.co/2017/05/02/how-to-lead-a-project.html) - Practical project leadership guidance
- [Maker's Schedule, Manager's Schedule](http://www.paulgraham.com/makersschedule.html) - Paul Graham on different work schedules
- [The Manager's Path](https://leaddev.com/career-progression/managers-path-camille-fournier-defines-key-challenges-managers) - Key challenges for managers
- [Engineering Management Philosophies and Why They Matter So Much](https://charity.wtf/2020/09/06/if-management-isnt-a-promotion-then-engineering-isnt-a-demotion/) - Leadership philosophy
